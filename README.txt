TASK 1 - TRANSFORMING WIREFRAMES INTO STATIC WEB PAGES

Project: DevSpace - Frontend Developer Static Web Page

Files:
- index.html
- css/style.css
- docs/Task_1_Technical_Report.docx

How to run:
1. Keep index.html and the css folder in the same project folder.
2. Open index.html in a web browser.
3. Test the navigation links and resize the browser window to check responsiveness.

Note:
The internship task description referred to a provided wireframe, but no wireframe asset was available with the supplied task instructions. Therefore, this project uses an original wireframe-inspired layout that demonstrates the exact requested structural elements: header/navigation, hero/content areas, skill cards, project cards, contact section, footer, semantic HTML, organized CSS, and responsive media queries.
